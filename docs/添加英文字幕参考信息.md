# 需求梳理

你的规则：

1. 原始英文文稿，**以标点为分割点**切分片段，每段字幕最大 **80字符（含空格）**，不能在单词中间截断，只能在标点处切。
2. 使用**按字符计时**：每个字符固定耗时（可配置），计算单条字幕基础时长。
3. 每条字幕有最小、最大时长限制；字幕之间加固定空隙；顺序累加生成SRT时间轴。
4. 输出标准 `.srt` 文件。

> 说明：英文包含字母、空格、标点，全部计入字符数。
> 注意：只能在标点处切分，不能把一个完整句子硬拆到单词中间。

## 字符耗时经验参考（可后续调参）

英文朗读，包含空格、停顿，经验参考：

- 偏慢（教学视频，适合阅读）：**0.06 秒 / 字符**
- 正常语速：**0.045 秒 / 字符**（推荐默认值）
- 偏快：**0.035 秒 / 字符**

> 举例：一条50字符字幕，0.045s/char → `50 * 0.045 = 2.25s`

配套约束（字幕行业通用，避免出现0.几秒一闪而过或者超长字幕）

- `min_duration`：单条字幕**最小时长 1.2s**，哪怕只有几个字符，不能比这个更小
- `max_duration`：单条字幕**最大时长 6.0s**，就算字符算出来更大，也钳位到最大值
- `gap`：字幕之间空隙，**0.25s**（上一条结束，隔0.25秒下一条才出现）

## 切分逻辑说明

切分标点集合：`. ! ? ; :`

> 规则：
>
> 1. 扫描文本，在以上标点后面做候选分割点；
> 2. 累积到下一个候选分割点时，统计当前片段总字符；
> 3. 如果 ≤80字符：保留为一条字幕；
> 4. 如果 >80字符：在上一个标点分割点断开；
> 5. **绝不拆分单词内部**，分割必须落在标点符号之后。

## 完整 Python 脚本

```python
import re

def seconds_to_srt_time(total_seconds: float) -> str:
    """浮点数秒转为SRT时间格式 HH:MM:SS,mmm"""
    hours = int(total_seconds // 3600)
    remain = total_seconds % 3600
    minutes = int(remain // 60)
    seconds = int(remain % 60)
    ms = int((remain - int(remain)) * 1000)
    return f"{hours:02d}:{minutes:02d}:{seconds:02d},{ms:03d}"


def split_by_punct_max_len(text: str, max_chars: int = 80) -> list[str]:
    """
    按标点分割文本，每条片段不超过max_chars字符（含空格）
    分割点： . ! ? ; :  ，只能在标点之后分割，不切割单词
    """
    # 找到所有标点的位置，作为候选分割点
    pattern = re.compile(r'(?<=[.!?;:])\s+')
    # split 会在标点后面空白处切分
    raw_fragments = pattern.split(text.strip())
    raw_fragments = [f.strip() for f in raw_fragments if f.strip()]

    result = []
    buffer = ""

    for frag in raw_fragments:
        if not buffer:
            buffer = frag
        else:
            combined = buffer + " " + frag
            if len(combined) <= max_chars:
                buffer = combined
            else:
                result.append(buffer)
                buffer = frag
    if buffer:
        result.append(buffer)
    return result


def text_to_srt_by_char(
    english_text: str,
    char_sec: float = 0.045,     # 每个字符耗时，核心可调参数
    max_chars: int = 80,         # 每条最大字符数(含空格)
    min_dur: float = 1.2,        # 单条最小时长
    max_dur: float = 6.0,        # 单条最大时长
    gap: float = 0.25            # 字幕间空隙秒数
) -> str:
    segments = split_by_punct_max_len(english_text, max_chars)
    srt_blocks = []
    current_start = 0.0
    idx = 1

    for seg in segments:
        char_count = len(seg)
        base_dur = char_count * char_sec
        # 钳位最小最大时长
        dur = max(min_dur, min(base_dur, max_dur))

        start = current_start
        end = current_start + dur

        s_start = seconds_to_srt_time(start)
        s_end = seconds_to_srt_time(end)

        block = f"{idx}\n{s_start} --> {s_end}\n{seg}\n"
        srt_blocks.append(block)

        idx += 1
        # 更新下一条起始时间，加上空隙
        current_start = end + gap

    return "\n".join(srt_blocks)


if __name__ == "__main__":
    input_text = """When you are writing subtitle scripts, you need to consider many practical details.
The length of each subtitle line should not exceed 80 characters including spaces.
We split sentences only at punctuation marks, and calculate duration based on character count.
You can adjust char_sec parameter to make the playback speed feel more natural."""

    srt_out = text_to_srt_by_char(input_text, char_sec=0.045)
    with open("out.srt", "w", encoding="utf-8") as f:
        f.write(srt_out)
    print("已生成 out.srt")
    print(srt_out)
```

# 参数调参参考表

| 使用场景             | char_sec（秒/字符） |
| -------------------- | ------------------- |
| 慢速教学视频         | 0.055 ~ 0.060       |
| 普通科普视频（默认） | 0.042 ~ 0.048       |
| AI快速朗读           | 0.033 ~ 0.040       |

> 使用方式：直接修改调用时的 `char_sec` 值，例如：

```python
srt_out = text_to_srt_by_char(input_text, char_sec=0.05)
```

## 边界情况说明

1. 如果某条分割出来的字幕字符非常少（比如只有5个字符），计算出来时长会小于`min_dur`，脚本会强制拉到最小时长，保证人眼可以看清。
2. 即使标点分割后片段字符很多，时长也不会超过`max_dur`。
3. 分割逻辑只会在 `. ! ? ; :` 后面切，不会把一个单词劈成两半。
