# 文本 → SRT 字幕生成器

一个零依赖的纯 JS 工具：把一段文本自动切成若干句字幕，按字数和语速生成带时间轴的
SRT 字幕文件。界面为 HTML 页面，启动时自动打开浏览器。

## 快速开始

### 方式一：双击启动（推荐）

双击 `text2subtitle.bat`，会自动启动本地服务并在默认浏览器中打开页面。
（优先使用 Node.js；若未安装 Node，则回退到 Python 的 `http.server`。）

### 方式二：命令行启动

```bash
node server.js
# 浏览器自动打开 http://127.0.0.1:8631/
```

### 方式三：直接双击 index.html

不经过本地服务直接打开页面也能使用；此时保存通过浏览器下载完成
（部分浏览器在 file:// 下不提供保存位置选择，见下文说明）。

## 页面用法

1. 左侧文本框粘贴需要转换的文本。
2. 顶部设置：**每句字数上限**（默认 20）、**语速**（默认 5 字/秒）、**字幕间隔**（默认 200 毫秒）。
3. 点中间上方的 **资源管理器** 按钮，在弹出的系统对话框中选择 SRT 文件的保存位置。
4. 点中间的 **生成** 按钮：右侧立即显示生成的 SRT 内容，并写入所选文件。
   - 未选择保存位置 / 浏览器不支持保存对话框时，会自动改为下载 `字幕.srt`。
   - 快捷键：在输入框内按 `Ctrl+Enter` 也可以生成。
5. 点 **载入示例** 可快速体验（会优先读取 `asset/字幕文件样本.srt` 的文本内容）。

## 生成逻辑

1. **断句**：按“每句字数上限”切分。换行符是硬分隔符：程序先按行拆分，
   每行内再从 `句子起点 + 字数上限` 的位置往回找第一个标点分隔符
   （中英文逗号、句号、问号、感叹号、分号、冒号、顿号、省略号、破折号等常用标点），
   句子在分隔符处收尾；若整行都没有分隔符，直接采纳整句（宁可超过字数上限，
   也不把词劈开，如“…Blender版的大提琴手林尼”不会被截成两半）；
   仅当窗口内没有、但行内后面还有分隔符时，才在字数上限处硬切。
   断句后**句尾的分隔符标点会被去掉**（如“观念：”→“观念”、“设计的——”→“设计的”），
   字幕更整洁；句中的标点保留。
2. **时间轴**：每条字幕时长 = `该句字数 ÷ 语速`（毫秒），并设最小时长 500ms；
   下一条从 `上一条结束时间 + 字幕间隔` 开始。首条从 00:00:00,000 开始。
3. **格式**：标准 SRT（UTF-8 无 BOM），每条为 `序号 / 时间轴 / 文本 / 空行`，
   时间轴格式 `HH:MM:SS,mmm`，与 `asset/字幕文件样本.srt` 一致。

## 文件结构

```
index.html            页面（左输入 / 中按钮 / 右预览 布局）
src/srt-generator.js  核心逻辑：断句 + 时间轴 + SRT 格式化（浏览器/Node 通用）
src/app.js            页面交互：保存对话框、生成、预览、下载回退
src/style.css         页面样式
server.js             零依赖静态服务，启动时自动打开浏览器
cli.js                命令行：node cli.js 输入.txt 输出.srt [--maxChars 20] [--speed 5] [--gapMs 200]
启动工具.bat          一键启动（UTF-8 无 BOM / CRLF）
asset/字幕文件样本.srt SRT 格式参考样本
```

## 命令行示例

```bash
node cli.js speech.txt 字幕.srt --maxChars 18 --speed 4
```

## 说明与假设

- 语速单位为“字/秒”，按字符数（含标点、空格）计算；中英文混排时可自行调整数值。
- 换行符（`\n`，CRLF / 单独 `\r` 统一归一化为 `\n`）是硬分隔符：
  先按行拆分，行内再按标点断句；行尾换行不会残留在字幕文本中。
- “资源管理器”保存按钮依赖浏览器的 File System Access API（Chrome / Edge 支持）；
  不支持或未选择路径时自动回退为直接下载。
- 如需 Electron 原生窗口版本，核心逻辑无需改动，把页面包进 Electron 主进程即可。

## 依赖

- 运行页面：任意现代浏览器（推荐 Chrome / Edge）。
- 启动脚本：Node.js ≥ 12（或 Python 3 作为回退）。
- 无任何 npm 依赖。
